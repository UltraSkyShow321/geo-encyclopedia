# 测试指南 — 世界地理百科全书

> 自动化 E2E（31 项）已全部通过；以下为人工验收清单，建议按顺序过一遍。

## 一、启动本地环境

```bash
# 终端 1（后端，端口 3000）
cd server
npm run dev

# 终端 2（前端，端口 5173，/api 自动代理）
cd web
npm run dev
```

浏览器打开 **http://localhost:5173**

> 已构建生产版：直接 `cd server && npm run start` 访问 http://127.0.0.1:3000 也可以。
